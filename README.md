# X 未回关检查

想整理 X 的关注列表，却不想自己对着“正在关注”和“关注者”来回翻，就做了这个小扩展。在已登录的 `x.com` 标签页点一下扩展图标，它会在浏览器里核对两份名单，找出没回关的人。结果按“正在关注”页面的顺序排列，还能保存为 Markdown 或 CSV，方便自己逐个查看。

## 安装和使用

1. 下载本仓库源码并解压。
2. 打开 `chrome://extensions/` 或 `edge://extensions/`，开启开发者模式，选择“加载已解压的扩展程序”，选中包含 `manifest.json` 的文件夹。
3. 在同一浏览器登录 X，切到 `https://x.com/` 的标签页，点击扩展图标。

扫描期间 X 标签页保持前台，扩展图标显示 `RUN`；结束后结果页自动打开。扩展会自动滚动、等待后续批次，并在必要时重试不完整的列表。只有两份名单均与主页人数吻合、顺序核对通过、关系标记无冲突，才开放导出。不完整时只显示未核实状态。

## 隐私

扩展没有服务器、分析统计或上传请求；只申请 `activeTab` 和 `scripting` 权限。代码不读取密码、Cookie、认证头、IP 或私信，也不执行关注、取关、发帖或发消息。扫描数据仅保存在结果页内存中，关闭结果页后消失。浏览器访问 X 本身仍使用你当前的网络连接，扩展不能隐藏出口 IP。

## 开发验证

需要 Node.js；运行 `npm test`。
